# KACIMI NEJMA VIP — Android starter project

## فتح المشروع
1. ثبّت Android Studio.
2. افتح مجلد `KACIMI_NEJMA_VIP`.
3. انتظر Gradle Sync.
4. شغّل التطبيق على هاتف Android أو اختر Build > Build APK(s).

## ملاحظات مهمة
- هذا مشروع أولي وليس APK جاهزاً.
- المشغل يدعم صيغ بث متوافقة مثل HLS/MP4 عند توفر رابط مباشر صالح ومصرّح لك باستعماله.
- روابط `video.xx.fbcdn.net` قد تكون مؤقتة أو موقعة أو تتطلب جلسة/صلاحيات، وقد لا تعمل في مشغل خارجي.
- استعمال نطاق Facebook لا يضمن أن اتصال البيانات سيُحتسب ضمن عرض *6. يجب تأكيد ذلك مع اتصالات المغرب.
- لا يتضمن المشروع قنوات أو روابط بث غير مرخصة.

- تمت إضافة وحدة MPEG-DASH لتجربة روابط `.mpd`.
