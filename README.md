# KACIMI NEJMA VIP

مشروع Android أولي بواجهة بنفسجية وست بطاقات للقنوات.

## البناء
افتح المجلد في Android Studio وانتظر Gradle Sync ثم اختر Build > Build APK(s).
يمكن أيضاً رفعه إلى GitHub وتشغيل Actions لبناء APK.

ملاحظة: هذه نسخة واجهة فقط ولا تتضمن روابط بث. استخدم فقط مصادر بث تملك حق استخدامها.
